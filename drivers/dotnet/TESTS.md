Conformance files are read with `ConformanceYaml` (test-only reader of the YAML subset of the suite; no
package dependency). Without `drivers/conformance/` the runners report one skipped case. The conformance
runner needs no server for tests made of runner operations only (codec, AST, connection-string, error-map,
SCRAM vectors and the retry scenarios); the others skip without `RUSTEGON_BIN_DIR` binaries (fail under
`CI=true`). The test node is started with client certificates optional, a client certificate for
`x509:CN=conf_x509` from `rustegon init --client-user`, and the authentication rate limits off (PD-098). The error
table is `drivers/conformance/generated/ErrorCodes.g.cs`, linked into the driver (PD-075). Driver
divergences found by the runners and the spec review: [`../DIVERGENCES.md`](../DIVERGENCES.md) §4.
